# Oreluno

Oreluno - экспериментальный ML-фреймворк на Rust, создаваемый с фундаментального уровня.

Проект находится на ранней стадии разработки. Текущая реализация демонстрирует базовый цикл символьной биграммной языковой модели и пока не является универсальным или готовым к промышленному использованию ML-фреймворком.

## Возможности

На текущем этапе реализованы:

- символьный токенизатор
- сбор статистики переходов между токенами
- вычисление распределений вероятностей
- выборка из дискретного распределения
- детерминированный генератор псевдослучайных чисел
- генерация текста с помощью биграммной модели
- запуск с текстом или файлом корпуса через CLI

Текущая версия не использует сторонних зависимостей Rust.

## Требования

- Rust с поддержкой edition 2024
- Cargo

## Быстрый старт

Клонируйте репозиторий:

```console
git clone https://github.com/404-undef/oreluno.git
cd oreluno
```

Запустите модель с текстом:

```console
cargo run -- --text "abba" --seed 42 --length 8
```

Или используйте файл корпуса:

```console
cargo run -- --train data/corpus.txt --seed 42 --length 100
```

## Параметры CLI

- `--text <text>` - использовать переданный текст как корпус
- `--train <path>` - загрузить корпус из файла
- `--seed <u64>` - начальное состояние генератора, по умолчанию `0`
- `--length <usize>` - количество генерируемых токенов, по умолчанию `0`
- `-h`, `--help` - показать справку

Если одновременно переданы `--train` и `--text`, используется файл из `--train`.

## Направление развития

Проект развивается от простых статистических моделей к собственным реализациям:

- тензорных операций
- автоматического дифференцирования
- нейронных сетей
- механизмов attention и Transformer
- языковых моделей
- оптимизированных CPU- и GPU-бэкендов

Планы могут меняться по мере развития архитектуры проекта.
